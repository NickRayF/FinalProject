# Итоги года — frontend

Это мой личный репозиторий с frontend-частью командного проекта «Итоги года». История была честно выделена из общего репозитория: здесь сохранены коммиты, которые затрагивали папку `frontend`.

Исходный командный проект: [GoOffer_HackathonAvito](https://github.com/NikName2021/GoOffer_HackathonAvito).

## О проекте

Приложение превращает историю действий тестового пользователя в интерактивные итоги года. Пользователь выбирает профиль, открывает имитацию главной страницы сервиса и запускает сценарий recap: анимированную историю с персональными карточками, диаграммами, достижениями, рекомендациями и миссией на следующий год.

Все профили, объявления и просмотры в проекте — демонстрационные.

Онлайн-демо: [statistics-helper.ru](https://statistics-helper.ru/).

## Мой вклад

Весь фронтенд целиком и полностью был написан мною, а именно:

- интерфейс выбора, создания, редактирования и удаления тестовых профилей;
- импорт активности из JSON и клиентская валидация данных;
- интеграция frontend с API: Axios, TanStack Query, Redux Toolkit для сессии;
- интерактивный сценарий итогов года: анимация открытия подарка, слайды, свайпы, графики и CTA;
- статичная адаптивная имитация страницы Авито и мок-страницы целевых действий;
- экспорт карточки итогов, миссии на следующий год и подключение продуктовой аналитики на фронте;
- раздел документации, сайдбар и интерфейс административной настройки карточек-достижений, возможность их редактировать и удалять;
- тестирование: Jest, Testing Library, Playwright, ESLint и production-сборка.

## Запуск frontend

Нужны Node.js 22+ и доступный backend API. По умолчанию приложение обращается к `http://localhost:8000/api`.

```bash
npm ci
cp .env.example .env.local
npm run dev
```

После запуска откройте <http://localhost:5173>.

Чтобы использовать другой адрес API, укажите его в `.env.local`:

```dotenv
VITE_BASE_API_URL=https://example.com/api
```

Полный запуск frontend вместе с backend, PostgreSQL и Redis описан в [README общего репозитория](https://github.com/NikName2021/GoOffer_HackathonAvito#readme).

│   ├── types/                      # TypeScript-типы API и доменных сущностей

## Пользовательский путь

1. Пользователь авторизуется и выбирает тестовый профиль.
2. Открывает имитацию главной страницы и запускает «Итоги года».
3. Открывает подарок и проходит слайды с результатами активности.
4. Изучает диаграммы, достижения, рекомендации и действия-переходы.
5. Выбирает миссию на следующий год и при необходимости экспортирует карточку итогов.

## Лицензия и материалы

Проект создан в учебно-демонстрационных целях. Страница сервиса является статичной имитацией: у неё нет реального торгового взаимодействия, а для изображений предусмотрены локальные заглушки при недоступности внешних ресурсов.
