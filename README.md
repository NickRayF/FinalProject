# «Итоги года» — frontend

Это мой личный репозиторий с frontend-частью командного проекта «Итоги года». История была честно выделена из общего репозитория: здесь сохранены коммиты, которые затрагивали папку `frontend`.

Исходный командный проект: [GoOffer_HackathonAvito](https://github.com/NikName2021/GoOffer_HackathonAvito).

## О проекте

Приложение превращает историю действий тестового пользователя в интерактивные итоги года. Пользователь выбирает профиль, открывает имитацию главной страницы сервиса и запускает сценарий recap: анимированную историю с персональными карточками, диаграммами, достижениями, сравнением с прошлым годом, рекомендациями и миссиями на следующий год.

Все профили, объявления, просмотры и целевые страницы CTA в проекте демонстрационные. Проект не подключён к реальным пользовательским данным и торговым операциям.

Онлайн-демо: [statistics-helper.ru](https://statistics-helper.ru/).

## Мой вклад

Frontend проекта реализован мною. Основные части работы:

- архитектура React-приложения, маршрутизация, адаптивный интерфейс и переиспользуемые компоненты;
- авторизация через backend-сессию и состояние аккаунта в Redux Toolkit;
- создание, просмотр, редактирование и удаление тестовых профилей;
- ручной ввод и массовый импорт объявлений и просмотров из JSON с клиентской валидацией;
- статичная адаптивная имитация страницы площадки и шаблонные страницы целевых действий;
- интерактивный recap: анимация открытия подарка, слайды, свайпы, CTA, диаграммы и графики;
- отображение рассчитанных backend сравнений годов и ориентировочного прогноза без повторного расчёта на frontend;
- выбор до трёх миссий на следующий год и отображение их прогресса в итогах и профиле;
- экспорт выбранных итогов в PNG и временные публичные ссылки для разрешённых карточек;
- административный интерфейс: CRUD дополнительных recap-карточек и редактирование встроенных ачивок, включая выбор и загрузку иконки;
- продуктовые события, обработка загрузки и ошибок API;
- unit- и E2E-тесты, линтер и production-сборка.

Авторство отдельных изменений можно проверить по истории GitHub и через `git blame`.

## Запуск

Полный проект с backend, PostgreSQL, Redis и frontend запускается через Docker Compose из корня [общего репозитория](https://github.com/NikName2021/GoOffer_HackathonAvito#readme):

```bash
docker compose up -d --build
```

В личном репозитории находится только frontend. Для его отдельного запуска нужны Node.js 22+ и доступный backend API.

Windows PowerShell:

```powershell
npm ci
Copy-Item .env.example .env.local
npm run dev
```

Linux/macOS:

```bash
npm ci
cp .env.example .env.local
npm run dev
```

После запуска откройте <http://localhost:5173>.

```dotenv
VITE_BASE_API_URL=http://localhost:8000/api
```

Полный запуск frontend вместе с backend, PostgreSQL и Redis описан в [README общего репозитория](https://github.com/NikName2021/GoOffer_HackathonAvito#readme).

```bash

npm run build
npx playwright install chromium
npm run test:e2e
```

Тесты покрывают API-функции, импорт данных, сессию, CTA, sharing, экспорт изображения, сравнение годов, миссии, профили, административные сценарии и основные пользовательские переходы.

## Пользовательский путь

1. Пользователь входит в аккаунт и выбирает или создаёт тестовый профиль.
2. Открывает статичную страницу площадки и запускает «Итоги года».
3. Открывает подарок и листает персональные слайды.
4. Изучает показатели, сравнение, прогноз, достижения и рекомендации.
5. Выбирает миссии, скачивает изображение или создаёт временную публичную ссылку.
